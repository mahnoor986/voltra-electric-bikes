# VOLTRA - Electric Bike Website

## Project Description

VOLTRA is a multi-page electric bike website created as a web development project. 
The website showcases electric bikes, their specifications, technology, company information, and contact details.

## Technologies Used

- HTML
- Tailwind CSS
- JavaScript
- Node.js
- Express.js

## Website Pages

- Home
- Bikes
- Technology
- About
- Contact
- References

## Features

- Responsive navigation bar
- Electric bike cards generated using JavaScript data
- Bike card slider
- Technology and company information sections
- Contact form connected to an Express POST endpoint
- Custom 404 Page Not Found
- References page with external reference websites
